# Curation tables: how they were made (AI-assistance metadata)

These tables are interpretations of NASA source documents, not NASA data. They were produced with an AI assistant
(Claude, Anthropic) and checked by code.

| folder / file | what it interprets | how it was made and checked |
|---|---|---|
| `tests/`, `steps/` | free-text cells of the BASS (PSI-26) and BASS-II (PSI-25) as-run test matrices: flow schedules, outcomes, material and flame configuration | two independent AI transcriptions per chunk, adjudicated (decision records in `docs/decisions.d/transcribe-*`, `adjudicate-*`, `audit-*`); every `raw_token` must be an exact substring of the cited source cell (`source_row` / `token_row` + `raw_column`), checked by `scripts/check_curation_provenance.py` and again by the dataset build, which excludes any row that fails |
| `evidence/` | Appendix A of the BASS-II Summary Report (NASA/TM-20210011385) | AI transcription; each observation text verified as a substring of its PDF column (`docs/decisions.d/evidence-tm-appendix-a.md`, `reconcile-*`) |
| `context_microgravity/` | tables from NTRS reports (DARTFire, Glenn 5.18 s drop tower, Saffire-IV/V/VI) | AI transcription, values checked against rendered page images (`docs/decisions.d/context-*`); context only, never used for modelling |
| `ground_flammability/` | normal-gravity flammability thresholds from NTRS reports | AI transcription, each value verified against the rendered page image; context only |
| `saffire_tests.csv`, `publication_points.csv` | Saffire-I/III context tests; points printed in publications for cross-checking | AI-assisted extraction with source title, URL and page per row; reference only |
| `audit/` | review notes for the tables above | written during the AI-assisted reviews |
| `_source_dumps/` | cell dumps of the source workbooks | generated by `scripts/dump_source_cells.py` (review aid only) |

Every row keeps its source file, sheet or page and row, so any value can be traced to the NASA document it came from. A
passing provenance check shows that the quoted text exists in the cited cell; it does not show that the interpretation is
the only possible one (see `docs/limitations.md`). Rules for these tables: `docs/CONTRACTS.md` section 2.
