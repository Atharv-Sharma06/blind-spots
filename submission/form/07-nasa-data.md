## Verification notes

- Method: `curl -sIL -A "Mozilla/5.0 (link-check)"` (HEAD, follow redirects, no cookies, no login), 2026-11-15
  about 15:57-16:03 EST. The status is the final status after redirects.
- All 48 table URLs: final 200, anonymous. Nothing needs a login.
- NTRS returned `503` (and a few timeouts) when 16+ requests were sent in parallel. Each NTRS URL was then
  rechecked one at a time and returned 200. This was rate limiting, not a broken link. If a judge sees a 503,
  reloading works.
- URLs given in their final (post-redirect) form, which differs from what the repo stores:
  - Human Integration Design Handbook: the repo stores
    `https://www.nasa.gov/sites/default/files/atoms/files/human_integration_design_handbook_revision_1.pdf`. It
    redirects (301) to `https://www.nasa.gov/wp-content/uploads/2015/03/human_integration_design_handbook_revision_1.pdf?emrc=...`.
    The table uses that path without the tracking parameter. Checked separately: 200.
  - NASA-STD-3001 web edition, NASA Glenn SoFIE page and SoFIE-MIST page: the repo stores them without the trailing
    slash. Each redirects once to the trailing-slash form used in the table.
- PSI DOIs also resolve to the PSI landing pages. The PSI page is the canonical landing URL, so the table uses it.
  Alternatives if needed: BASS `https://doi.org/10.60555/58h4-dy80`, BASS-II `https://doi.org/10.60555/4qc4-de67`
  (both 200 after one redirect). The SAFFIRE DOIs in `/api/sources` are 10.60555/0t15-1z43 (I), 10.60555/2chp-m469 (II)
